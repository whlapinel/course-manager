Unit 3 Quiz:

1. While Loop Basics

Question: Write a while loop that prints the numbers from 1 to 5.

Hint:

  1. Create a variable, say i, and set it to 1.
  2. Use while i <= 5:.
  3. Print i and then increment i by 1 (e.g., i = i + 1).

2. Repeating a Statement

Question: Write a while loop that prints "Python is fun!" exactly 3 times.

Hint:

  1. Create a counter variable starting at 1.
  2. Loop while the counter is less than or equal to 3.
  3. Print the phrase and increment the counter by 1 each time.

3. Even Numbers with a While Loop

Question: Write a while loop that prints the even numbers from 2 to 10.

Hint:

  1. Start your counter at 2.
  2. Use while i <= 10:.
  3. Print i, then increment i by 2.

(Alternatively, if you want to increment by 1, you can check if i % 2 == 0 before printing.)

4. For Loop Over a String

Question: Use a for loop to print each character in the string "Hi!".

Hint:

  • Remember you can loop directly over any string in Python with for char in "Hi!":.
  • Just print char inside the loop.

5. For Loop with Range

Question: Use a for loop to print all numbers in the range 0 to 4.

Hint:

  • Use range(5) in the for loop, like for i in range(5):.
  • Then print i.

6. Looping Through a List

Question: Create a list called fruits that contains ["apple", "banana", "cherry"]. Then use a for loop to print each fruit.

Hint:

  • Define your list with fruits = ["apple", "banana", "cherry"].
  • Then for fruit in fruits: will let you print each item.

7. Summing a List of Numbers

Question: Create a list of 5 numbers (any numbers you like). Use a for loop to calculate the sum of all the numbers, then print the sum.

Hint:

  1. Initialize a variable, say total = 0.
  2. For each number in your list, add it to total.
  3. Print total after the loop finishes.

8. Countdown with a While Loop

Question: Write a program that uses a while loop to count down from 5 to 1, and then print "Blast off!".

Hint:

  1. Create a variable, say count, and set it to 5.
  2. Use while count >= 1:.
  3. Print count, then do count = count - 1.
  4. After the loop, print "Blast off!".

9. Favorite Animals with a For Loop

Question: Make a list containing three of your favorite animals. Use a for loop to print a sentence about each animal (for example: "I love cats!").

Hint:

  • Suppose your list is animals = ["cats", "dogs", "rabbits"].
  • Then for animal in animals: will let you print, for instance, "I love " + animal.

10. Double the Numbers

Question: Create a list of three numbers, such as [10, 20, 30]. Use a for loop to print double each number (that is, 2 × that number).

Hint:

  • For each number in the list, you can print number * 2.
  • If your list is [10, 20, 30], the output should be 20, 40, 60.
