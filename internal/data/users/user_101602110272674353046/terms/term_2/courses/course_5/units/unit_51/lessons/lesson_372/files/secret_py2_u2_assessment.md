# Unit 2 Assessment
Choose one of the following to build. Submit your code as a .zip file consisting solely of python files.

## Requirements to incorporate:
- At least one `for` loop
- At least one `while` loop
- At least one nested loop (can be same loop as one of the above)
- At least one `if` statement
- At least three functions
- Use at least one method in the `datetime` module

Otherwise, have fun and be creative with it!

## Ideas
1. **To-Do List**  
   - Allow users to add, remove, and view tasks.  
   - Save tasks in a text file for persistence.  

2. **Flashcard Quiz**  
   - Users answer random questions from a predefined set.  
   - Track the number of correct and incorrect answers.  

3. **Rock, Paper, Scissors**  
   - Play against the computer using random choices.  
   - Keep score of wins, losses, and ties.  

4. **Unit Converter**  
   - Convert between units (miles to kilometers, Fahrenheit to Celsius, etc.).  

5. **Number Guessing Game**  
   - The program selects a random number, and the user has to guess it.  

6. **Simple Expense Tracker**  
   - Users enter income and expenses, and the program calculates balances.  

7. **Dice Roller**  
   - Simulate rolling different types of dice (D6, D20, etc.).  

8. **Password Generator**  
   - Generate random passwords with different complexity levels.  

9. **Mad Libs Generator**  
   - Ask users for words and insert them into a predefined story template.  

10. **Countdown Timer**  
    - Allow users to set a timer and notify them when time is up.  

## **Rubric (100 Points Total)**  

| Category                  | Points | Description |
|---------------------------|--------|-------------|
| **Runs Without Error** | **40** | The program runs without crashing or throwing errors. If errors exist, they should not prevent core functionality. Partial credit may be awarded if issues are minor and easily fixable. |
| **Meets All Requirements** | **20** | Includes at least one `for` loop, one `while` loop, one nested loop, one `if` statement, three functions, and one method from `datetime`. |
| **Functionality** | **15** | The program performs the intended task correctly. It successfully implements the chosen project (e.g., To-Do List saves tasks, Flashcard Quiz tracks scores, etc.). Partial credit given for mostly functional implementations with minor issues. |
| **Code Organization & Readability** | **10** | Code is well-structured with clear function usage, variable names, and comments where necessary. |
| **Creativity & Effort** | **10** | The project includes additional features or unique elements beyond the basic requirements, showing effort and creativity. |
| **Proper File Submission** | **5** | The project is submitted as a `.zip` file containing only Python files. |
